วัสดุดีหรือไม่ดีดูอย่างไร
สตว. สทช.14 กระบี่ · General Test

3. วัสดุดีหรือไม่ดีดูอย่างไร

ตัดสินด้วยผลทดสอบเทียบเกณฑ์ มทช. · ข้อสังเกตด้วยตาใช้คัดกรองเบื้องต้นเท่านั้น

หลักตัดสินปัญหาที่พบบ่อยดินลูกรังหินคลุกทรายหิน คอนกรีต/ACเหล็กผลิตภัณฑ์

✓หลักการตัดสิน

  1. วัสดุดี = ผลทดสอบผ่านเกณฑ์ใน หน้าเกณฑ์คุณสมบัติ ครบทุกรายการ จึงอนุญาตให้ใช้
  2. ไม่ผ่าน = ปรับปรุงวัสดุหรือเปลี่ยนแหล่ง แล้วเก็บตัวอย่างใหม่ส่งทดสอบ
  3. ห้ามนำวัสดุที่ยังไม่ผ่านการทดสอบมาใช้ (เช่น มทช.251-2569 ทรายรองถนนคอนกรีต)

ข้อสังเกตด้วยตาด้านล่างเป็น ข้อสังเกตเบื้องต้น รอ สตว. ตรวจทานและใส่ภาพจริง ไม่ใช้แทนผลทดสอบ

!ปัญหาอุปสรรคที่พบบ่อย

รวบรวมจากการรับตัวอย่างและผลทดสอบของ สตว. · เพิ่มรายการได้ที่ปุ่ม "จัดการรูปและปัญหา" ท้ายหน้า

1ดินเดิม / ดินถม

[ภาพดินถมที่ดี]

✓ ผ่านเกณฑ์เมื่อ

  • C.B.R. ≥ 4% และ Swell ≤ 4% (ดินทั่วไป) มทช.201-2545
[ภาพดินขาดคุณสมบัติ]

✗ สัญญาณเตือน [รอตรวจทาน]

  • มีรากไม้ เศษพืช หรือดินอินทรีย์สีดำปน
  • ดินเหนียวจัด เปียกแล้วเหนียวติดมือ แห้งแล้วแตกระแหง
  • แหล่งเปลี่ยน สีหรือเนื้อดินต่างจากที่ส่งทดสอบ

2ลูกรัง / วัสดุรองพื้นทาง

[ภาพลูกรังที่ดี]

✓ ผ่านเกณฑ์เมื่อ

  • ผ่านทุกรายการในตาราง 2-10 ลำดับ 4 (Compaction, Gradation, C.B.R., Swelling, Atterberg, % Abrasion) [ค่าเกณฑ์ตาม มทช. รองพื้นทาง]
[ภาพลูกรังขาดคุณสมบัติ]

✗ สัญญาณเตือน [รอตรวจทาน]

  • เม็ดลูกรังน้อย มีดินเหนียวมาก
  • เม็ดผุ บี้แตกด้วยนิ้ว
  • เปียกแล้วเละ ลื่น

3หินคลุก (พื้นทาง)

[ภาพกองหินคลุกที่ดี]

✓ ผ่านเกณฑ์เมื่อ

  • LL ≤ 25 · PI ≤ 6 · LA ≤ 40 · Soundness ≤ 9 · C.B.R. ≥ 80/90 · ขนาดคละอยู่ในช่วง มทช.203-2557
  • ไม่มีหินดินดาน (Shale) · ส่วนละเอียดเป็นวัสดุชนิดเดียวกับส่วนหยาบ มทช.203-2557
[ภาพวัสดุขาดคุณสมบัติ]

✗ สัญญาณเตือน [รอตรวจทาน]

  • มีก้อนดินเหนียวหรือหินดินดานปน
  • เม็ดผุ บี้แตกด้วยมือได้
  • แยกตัว (Segregation): หินใหญ่กับส่วนละเอียดอยู่คนละส่วนของกอง
  • เปียกแล้วเหนียวติดมือ แสดงว่ามีส่วนละเอียดที่เป็นดินมาก

4ทราย (ถม / รองถนนคอนกรีต / คอนกรีต)

[ภาพทรายที่ดี]

✓ ผ่านเกณฑ์เมื่อ

  • ทรายรองถนนคอนกรีต: เม็ดโตสุด ≤ 9.5 มม. · ผ่านเบอร์ 200 ≤ 10% · Non-Plastic มทช.251-2569
  • ทรายคอนกรีต: FM 2.3–3.1 มทช.101-2563
[ภาพทรายขาดคุณสมบัติ]

✗ สัญญาณเตือน [รอตรวจทาน]

  • มีดินหรือโคลนปน กำแล้วเป็นก้อน
  • มีเศษไม้ ใบไม้ เปลือกหอยปน
  • เม็ดละเอียดมากคล้ายฝุ่น

5หินสำหรับคอนกรีตและแอสฟัลต์คอนกรีต

[ภาพหินที่ดี]

✓ ผ่านเกณฑ์เมื่อ

  • ผ่าน % Abrasion, Flakiness, Elongation, Gradation, Specific Gravity [ค่าเกณฑ์ มทช.209/มทช.101]
  • หินคอนกรีตขนาดโตสุด ≤ 40 มม. มทช.101-2563
[ภาพหินขาดคุณสมบัติ]

✗ สัญญาณเตือน [รอตรวจทาน]

  • หินแบนหรือยาวมาก (Flaky / Elongated)
  • มีฝุ่นหรือดินเคลือบผิว
  • หินผุ สีไม่สม่ำเสมอ

6เหล็กเสริม

[ภาพเหล็กที่ดี]

✓ ผ่านเกณฑ์เมื่อ

  • ผลแรงดึงจุดคลาก แรงดึงสูงสุด % การยืด ผ่านตาม มอก.20 / มอก.24 · TS/YS ≥ 1.25 มทช.103-2569
[ภาพเหล็กขาดคุณสมบัติ]

✗ เมื่อไม่ผ่าน

  • ทั้งชุดใช้ไม่ได้ มทช.103-2569
  • สัญญาณเตือน: สนิมขุมลึก เหล็กคด ขนาดไม่ตรงที่ระบุ [รอตรวจทาน]

7ผลิตภัณฑ์สำเร็จรูป (ท่อ สี ป้าย ยาง)

  • ท่อ คสล.: ตรวจสอบใบรับรอง มอก. และตรวจคุณภาพ ขนาดในสนาม
  • ป้ายจราจร / ตีเส้น: วัดขนาด ค่าสะท้อนแสงในสนาม
  • ยาง: ใช้ของใหม่หรืออยู่ในอายุการเก็บ เพราะการเก็บนานอาจเปลี่ยนคุณสมบัติ คู่มือ QC แอสฟัลต์คอนกรีต ทช. 2558 ข้อ 1.4
